# Matheportal- Konvetionen

## Frontend

- Angular Standalone Components
- NgRx für fachlichen State
- Components dispatchen Intent-Actions; fachliche Abläufe in Effects
- BEM-Semantik im Component-SCSS
- keine hardcodierten Farben/Spacing/Radien, sondern shared-ui-theme
- @use 'mp-theme' as mp-theme

## Dateien

- der branch develop unter https://github.com/heike2718/matheportal ist die aktuell stabile Version
- aktuelle Architekturdateien sind kanonisch
- Dateien mit Versionssuffix sind Arbeitsstände und nicht maßgeblich
